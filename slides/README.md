# Slides

Personal tooling for meeting slides; not part of the experiment code.

```
slides/
  scripts/
    deck.py                    helpers: start from the template in files/ (keeps its theme and layouts),
                               add title, text and figure slides
    <date>_<topic>.py          one script per deck: its text and figures
  decks/
    <date>_<topic>.pptx        the deck generated by the script with the same name
  requirements.txt
```

New deck: copy the latest script in `scripts/`, change the text and figures, run it.

```
pip install -r slides/requirements.txt
python slides/scripts/2026-10-05_abstain_mismatch.py   # writes slides/decks/2026-10-05_abstain_mismatch.pptx
```

Figures come from `outputs/<experiment>/figures/`. Check the result visually: with `layout="below"`, bullets that wrap
to a second line run under the figure.
